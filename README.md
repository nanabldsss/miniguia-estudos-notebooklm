**Miniguia de Análise de Dados com NotebookLM**

**Sobre o projeto**
Este projeto foi desenvolvido como parte de um desafio prático da **DIO**, com o objetivo de explorar a Inteligência Artificial como uma ferramenta de aprendizagem ativa. A proposta consiste na criação de um caderno temático utilizando o NotebookLM, combinando curadoria de fontes, engenharia de prompts, pensamento crítico e organização do conhecimento.
O tema escolhido para este projeto foi "Fundamentos de Análise de Dados", uma área de interesse dentro da minha formação em Ciência da Computação e dos meus objetivos de desenvolvimento profissional.

**Objetivos**
Os principais objetivos deste projeto são:
- Compreender os fundamentos da análise de dados;
- Entender conceitos relacionados à coleta, tratamento e exploração de dados;
- Conhecer a importância da visualização de dados;
- Utilizar Inteligência Artificial de maneira crítica durante o processo de aprendizagem;
- Desenvolver melhores práticas para criação de prompts;
- Aprender a avaliar e comparar informações provenientes de diferentes fontes;
- Registrar os conhecimentos adquiridos em um material de estudo reutilizável.

**Uso do NotebookLM**
O NotebookLM foi utilizado como ambiente de aprendizagem baseado nas fontes selecionadas, com a finalidade de:
- Identificar conceitos fundamentais;
- Comparar diferentes conceitos;
- Encontrar relações entre os conteúdos;
- Solicitar exemplos práticos;
- Consolidar informações de diferentes fontes.

**Prompt 1 — Pergunta ampla**
"Explique o que é análise de dados."
A resposta apresentou uma definição geral, mas não aprofundou as etapas do processo nem apresentou uma estrutura adequada para estudo, o fato do prompt ser muito amplo não estabelece nível de conhecimento, formato desejado e fontes que deveriam ser utilizadas.
**Prompt 2 — Contextualização**
"Explique o conceito de análise de dados para uma estudante de Ciência da Computação que está começando a estudar a área. Organize a resposta em definição, principais etapas, exemplos práticos e ferramentas utilizadas."
A resposta passou a apresentar uma estrutura mais adequada para aprendizagem, com explicações mais direcionadas e exemplos. Vemos que adicionar contexto sobre o estudante e especificar o formato esperado ajuda a tornar a resposta mais útil.
**Prompt 4 — Pensamento crítico**
"Com base nas fontes disponibilizadas, apresente os principais conceitos de análise de dados. Para cada conceito, explique sua importância, apresente um exemplo prático e indique possíveis erros de interpretação ou limitações."
Esse prompt foi utilizado para ir além da simples definição dos conceitos e incentivar uma análise mais crítica.

**Problemas identificados**
- Perguntas muito abertas produziram respostas corretas, porém pouco direcionadas ao objetivo do estudo.
- Algumas respostas apresentaram muitos conceitos simultaneamente, dificultando a organização do estudo.
- Mesmo utilizando fontes selecionadas, as respostas da IA precisaram ser analisadas criticamente.

**Glossário**
| Conceito | Definição |

| **Análise de Dados** | Processo de examinar e interpretar dados para obter informações úteis. |
| **Dataset** | Conjunto de dados utilizado para análise. |
| **Variável** | Característica ou atributo que pode assumir diferentes valores. |
| **Outlier** | Valor que apresenta comportamento significativamente diferente do restante dos dados. |
| **Dados ausentes** | Informações que deveriam estar presentes, mas não possuem valor registrado. |
| **ETL** | Processo de Extração, Transformação e Carga de dados. |
| **KPI** | Indicador utilizado para acompanhar o desempenho em relação a determinado objetivo. |
| **Dashboard** | Painel visual utilizado para apresentar informações e indicadores. |
| **SQL** | Linguagem utilizada para consultar e manipular bancos de dados relacionais. |
| **Data Visualization** | Representação visual de dados para facilitar sua interpretação. |
| **Análise Exploratória** | Processo de investigação inicial de um conjunto de dados para identificar padrões e características. |
| **Correlação** | Medida da relação entre variáveis. |
| **Insight** | Informação relevante obtida a partir da análise dos dados. |
